일반적인 구현 세부사항까지 매번 승인을 기다리지 않는다. 미정 결정이 필요한 작업만 질문하고 독립적인 작업을 진행한다.
중요한 선택은 [결정 양식](../templates/decision.md)으로 근거·결정자·날짜를 남긴다. 서로 다른 문서가 충돌하면 근거를 확인하고 함께 갱신한다.
