## 범위와 완료 조건

- 원본 출처와 commit을 기록하고 원본 저장소 없이 필요한 문서를 읽을 수 있다.
- 사용자의 intent.md를 보존해 포함하고 제품 제약·P0·열린 결정에 연결한다.
- 앱 코드 생성 금지 등 원본 전용 규칙을 제거하고 Codex·Claude 진입점을 일치시킨다.
- 팀 시작·작업·검증·인수인계·PR 양식과 ourroad 시나리오를 갖춘다.
- 재현 가능한 문서 검사를 실행하고 실제 결과와 미검증을 기록한다.
- 변경을 GitHub PR로 공유한다. 팀원의 승인·main 머지·실제 앱 구현은 이 작업의 완료 주장이 아니다.
- 원본 삭제·Archive는 실행하지 않는다. 필요한 정리 조건을 안내한다.
