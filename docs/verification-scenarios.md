# UNSEEN 동작 검증 시나리오

기준: [제품 기획](../intent.md) §6·7·11·12. 아래는 **실행 계획**이며 앱 결과가 아니다.
현재 모든 앱 시나리오는 NOT_RUN이다. 사용 버전·절차·초기 상태·실제 결과는 작업 문서나 [검증 양식](../templates/verification.md)에 기록한다.
경로·이야기·시각은 합성 데이터로 준비하고 Mock/실제 SDK를 구분한다.

## 데모 연결

1. A의 동의·주행·주차·작성 → B의 공유 구간 통과·주차·발견·이어쓰기 → C의 발견 순서로 재현한다.
2. 운전 중 소셜 조작이 없고 타인의 출발지·목적지·실시간 위치가 공개되지 않는 것을 보여준다.
3. 시뮬레이션 시간·합성 경로·시드 콘텐츠를 명시한다. 빌드 성공과 실제 차량 신호 성공을 별도 기록한다.

Phase 0는 U-01·03~07의 수집/제한 가능성을 먼저 확인한다. 전체 P0 완료에는 경로·콘텐츠·삭제·실패/복구 항목도 필요하다.
보관 기간·민감 구간·매칭 기준이 미정인 상태를 테스트 성공으로 간주하지 않는다.
