## 공모 내용·자격

차량 데이터·기능·이동 맥락으로 운전자와 동승자의 문제를 해결하는 앱을 개발하는 공모전이다.
대학(원)생·일반인·스타트업이 참가할 수 있고, 개인 또는 대표자를 포함한 최대 5인 팀이 가능하다.
시상 부문은 대학생과 일반(스타트업 포함)이다. 특정 예시 주제로 제한하지 않는다.

## 제출

| 구분 | 요구 |
| --- | --- |
| 필수 | 접수양식 자체가 기획서. 전원 개별 동의·서명·날짜 |
| 선택 | 시연 영상, GitHub 소스와 APK. 개발 수준에 따른 가산점 |
| 별도 선택 | 숏폼 링크. 본상 가산점 없음 |
| 접수 | 대표자가 팀원 전원 CC, appdevchallenge@hyundai-partners.com으로 이메일 |
| 제목 | `[차량용 앱 개발 공모전] 팀명(개인은 성명)_대표자명` |

GitHub 제출 시 실행 가능한 release APK를 `apk/`에 두고 `팀명_앱이름_release.apk`로 명명하도록 안내한다.
용량 초과 시 GitHub Releases 링크를 사용한다. README에는 앱 소개·실행법·환경·APK 위치를 기록한다.
Private 저장소도 가능하지만 공지된 심사용 계정의 접근을 마감 전에 확인해야 한다.
수정 제출은 최초 발신 주소로 전체 자료·서명 동의서를 다시 보내고 팀원 전원을 CC한다.
마감 전 마지막 제출본이 최종본이다.
[제출 방법 및 접수양식 다운로드](https://appdevchallenge.auto-hmg.io/guide/submission)

접수양식 DOCX의 다운로드 경로는 확인했으나 파일 내부 항목은 이번 조사에서 직접 열람하지 않았다.
웹 안내에 이메일 접수와 ‘제출 페이지 입력’ 표현이 함께 있어, 실제 입력 채널이 필요하면 운영사무국에 확인한다.
심사용 GitHub 계정명은 열람한 페이지에서 확인되지 않았으므로 임의 계정을 초대하지 않는다.

## 참가·출품 공지에서 확인할 사항

공지에는 1차 합격 20팀의 실제 동작 앱 시연과 최종 10팀의 전시용 APK·현장 참여 의무가 있다.
순수 창작물과 제3자 권리 준수가 요구되며, 기 발표 타 공모전 수상작은 제외된다고 안내한다.
출품 지식재산권은 응모자에게 있으나, 수상작의 통상실시권 협의·4개월 우선협상권 등의 조건도 명시되어 있다.
원문 조건을 참가자가 확인해야 하며, 여기서 별도의 법률 해석을 하지는 않는다.
AI 도구 사용의 별도 허용·금지 조건은 이번 열람 자료로 확인하지 못했다.

## 하네스에 반영한 연결점

아래는 공식 규정 자체가 아니라 조사에 따른 개발 지원 방식이다.

- 작업 문서에 고객 문제·차량 맥락·SDK 근거를 연결한다.
- Mock 화면, 빌드 성공, 실제 Pleos 시연을 구분해 기록한다.
- 앱 저장소에서 코드와 release APK를 재현 가능하게 연결할 수 있도록 검증 양식을 준비한다.
- 서명 동의서·연락처는 하네스 저장소에 포함하지 않는다.
- 접수 자료 제출·심사 계정 초대·선택 산출물 제작은 이번에 실행하지 않았다.

변경 공지는 [공지사항](https://appdevchallenge.auto-hmg.io/notice), 미확인 운영 사항의 문의처는 [도움말·문의](https://appdevchallenge.auto-hmg.io/guide/help)에서 확인한다.
