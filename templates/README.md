# 작업 양식

필요한 양식만 복사해 작업과 함께 보관한다. 빈 양식과 실제 수행 결과를 혼동하지 않는다.

| 양식 | 사용 시점 |
| --- | --- |
| [task.md](task.md) | 새 기능·조사·수정 작업의 범위와 담당 정의 |
| [api-contract.md](api-contract.md) | SDK/API 사용 전 근거·권한·가용성 확인 |
| [verification.md](verification.md) | 명령·환경·시나리오·증거를 상세 기록 |
| [handoff.md](handoff.md) | 사람 또는 AI 도구를 바꿀 때 |
| [decision.md](decision.md) | 팀이 중요한 선택을 확정했을 때 |

자리표시자는 확인된 내용으로 바꾸고, 알 수 없는 값은 미정 또는 NOT_RUN으로 남긴다.
